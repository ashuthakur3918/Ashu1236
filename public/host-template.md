# Frontier Host duplication guide

Duplicate this page for each host by replacing the host-specific fields in index.html and app.js.

## Host fields
- Host name
- Hero photo
- Host portrait
- Expedition dates
- Route copy / map
- Video embed
- Bike model / support details
- Accommodation details
- Price / deposit
- Inclusions / exclusions
- FAQ answers
- Terms URL
- Booking URL
- Deck URL
- Instagram URL

## Tracking
UTM parameters are captured as source and page/CTA/form/thank-you events are stored in Postgres.

Recommended campaign links:
?utm_source=instagram
?utm_source=youtube
?utm_source=host
?utm_source=partner

## Production assets
Replace the placeholder image/video blocks with real assets. Keep the section IDs and form endpoint unchanged so the funnel and tracking remain reusable.
